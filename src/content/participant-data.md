IPR MEDIA предоставляет страницы тестирования, принимает и хранит работы участников, обеспечивает сохранность резервной копии и передачу результатов организатору. ## 2. Какие данные используются

Регистрация проходит во внешней форме ЧГПУ. На странице теста участник повторно указывает фамилию, имя и адрес электронной почты, использованный при регистрации, чтобы организатор мог сопоставить работу с участником.

При прохождении теста обрабатываются направление и вариант теста, ответы на задания, идентификатор попытки, время начала и окончания, длительность, сведения об автоматическом завершении и прослушивании аудио, а также технические сведения браузера, необходимые для работы теста и разбора ошибок. Если для теста настроено оценивание, сохраняются баллы по заданиям, частям и общий результат. Дата рождения, телефон, данные законного представителя и сведения о специальных условиях из регистрационной формы в базу тестирования IPR MEDIA не передаются.

Во время прохождения незавершённые ответы и введённые данные могут временно сохраняться в браузере участника для восстановления после обновления страницы. После подтверждённой отправки теста они удаляются из локального хранилища приложения. На общем устройстве участнику рекомендуется также очистить данные сайта в браузере.

## 3. Для чего и как обрабатываются данные

Данные используются только для проведения первого тура олимпиады: приёма и сохранения работ, сопоставления с регистрацией, проверки заданий, подведения итогов, ответа на обращения участников и восстановления результата при техническом сбое.

При завершении теста работа сначала сохраняется в базе технического партнёра. После успешного сохранения участник видит подтверждение завершения. Результат передаётся ЧГПУ через согласованный электронный канал, в том числе в таблицу результатов, которую использует организатор. Если дополнительная отправка не удалась, сохранённую работу можно передать повторно без создания второй попытки. Доступ к индивидуальным данным имеют только сотрудники ЧГПУ и IPR MEDIA, которым он нужен для проведения олимпиады и технической поддержки.

IPR MEDIA не использует данные тестирования для рекламы, продвижения собственных продуктов, профилирования или рассылок и не публикует персональные результаты. Решение о публикации итогов на ресурсах ЧГПУ и необходимое для этого основание определяет организатор отдельно.

## 4. Участие несовершеннолетних

Для несовершеннолетнего участника вопросы участия и обработки его данных оформляет ЧГПУ с участием законного представителя в рамках регистрации. Тестовая страница не заменяет подтверждение законного представителя: технический партнёр принимает работу участника, зарегистрированного организатором и получившего ссылку на свой тест.

## 5. Хранение и обращения

Данные тестирования хранятся в течение проведения олимпиады и периода рассмотрения обращений по её итогам. Резервная копия у IPR MEDIA удаляется не позднее 31 марта 2027 года, если обязанность более длительного хранения не установлена законом. Данные в системе регистрации и таблице организатора хранятся по правилам ЧГПУ.

По вопросам регистрации, участия, проверки и итогов обратитесь к организатору: chechgpi@mail.ru. По вопросам технического хранения и удаления данных теста обратитесь к IPR MEDIA: adm@iprmedia.ru. Участник или его законный представитель может запросить сведения об обработке данных, исправление ошибочных сведений и удаление данных, если для их дальнейшего хранения нет основания. Запрос рассматривается организацией, к которой он относится, с участием другой стороны при необходимости.
