ОШИБКИ И НЕСООТВЕТСТВИЯ
Высокий приоритет: размещение не соответствует HANDOFF.md. На указанном URL остаётся HTTP без перенаправления на HTTPS; isSecureContext=false. Document.scripts содержит /@vite/client и /src/app.js. Это dev-раздача Vite вместо требуемой публикации dist/. Формы и API передают данные по HTTP. Наличие отдельного HTTPS-адреса не проверялось.
Низкий приоритет: публичный /thanks/ показывает демо-экран РКИ-1: «ответы никуда не отправлены», «Результат на сервере не сохранён». Основные тесты завершаются на собственном URL правильной благодарностью; основной путь это не ломает. Публичное демо-превью следует убрать из рабочей публикации или явно отделить.
Низкий приоритет: на /thanks/ выбор EN сбрасывается на RU после обновления. На основных информационных страницах язык сохраняется. Сам /thanks/ отдельно не указан как обязательный маршрут HANDOFF.md — это дополнительное наблюдение.

ЧТО НЕВОЗМОЖНО ПОДТВЕРДИТЬ БЕЗ MYSQL И СЕРВЕРНОГО ДОСТУПА
Ответ API saved:true — подтверждение приложения, но не независимое доказательство записи в MySQL. Не проверены фактические строки, исходные ответы, технические поля, транзакционный commit, баллы по заданиям/частям/суммарно и оценивание по приватному Code.gs.
Для проверки Google нужны также таблица, Apps Script и очередь: попадание каждого sid в нужный лист, JSON ok:true от Google, повтор после отказа Google и отсутствие дубликатов. Один MySQL-доступ не подтверждает содержимое Google-таблицы.
MySQL и Google не отключались. Реальные сбои MySQL, независимость благодарности от доступности Google, досылка и дедупликация в БД не подтверждены.
Не проверены серверные версии Node.js/MySQL, расположение приватного Code.gs и отсутствие ключей во всех опубликованных файлах, резервные копии, мониторинг очереди, автозапуск и восстановление после перезапуска.
npm run build, npm test и npm run test:server не запускались: проверялся удалённый сайт; локальные команды не удостоверяют удалённую сборку, серверным тестам нужна отдельная тестовая БД.
