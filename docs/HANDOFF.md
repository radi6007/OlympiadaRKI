# ТЗ на запуск олимпиады «Русский язык: код единства»

Задача разработки — разместить проект на рабочем домене, подключить инфраструктуру и проверить полный путь участника. Интерфейс, шесть тестов и серверная интеграция уже реализованы; использовать текущий проект как основу, сохранив согласованные тексты и логику.

## Проект и доступ

Репозиторий: https://github.com/radi6007/OlympiadaRKI

Рабочая ветка: main. Репозиторий публичный: просмотр, скачивание и клонирование доступны без приглашения.

Для внесения изменений напрямую передать владельцу GitHub-логины разработчиков для приглашения. Также можно работать через fork и pull request.

Для рабочего запуска заказчик отдельно передаёт приватный Code.gs с ключами ответов и доступ к Google-таблице/Apps Script. Команда размещения предоставляет домен, сервер и реквизиты MySQL. Секретов и данных локальной базы в Git нет.

## Что сохранить

- Главная, шесть отдельных страниц направлений и шесть тестов: `/rki-1`–`/rki-3`, `/rku-1`–`/rku-3`; тесты — по адресу направления с `/test/`. Прямые ссылки и обновление страницы должны работать на сервере.
- На главной шесть блоков РКИ/РКУ — только информация, без ссылок, стрелок перехода и выбора потока. Заголовок — «Направления олимпиады». Ссылку на свой поток участник получает индивидуально от организаторов.
- Стили продукта РКИ, адаптивность, логотипы ЧГПУ и IPR РКИ, ссылки организаций и существующую регистрационную Google-форму. На главной — «школьники и студенты». Для РКИ указаны уровни, для РКУ сохранены возрастные группы.
- На информационных страницах остаётся RU/EN. Внутри тестов интерфейс русский, общего переключателя нет. В РКИ-1 и РКИ-2 кнопка English раскрывает существующий перевод конкретной технической подсказки. Задания и варианты ответов не переводить и не редактировать. РКИ-3 и РКУ — только русский.
- Все 33 задания каждого теста, аудио, форматы ответов, навигацию, экранную клавиатуру, таймер 90 минут, автозавершение и восстановление после обновления. РКУ-1/2 — одно прослушивание, остальные — два.
- Страницу `/data-processing`, ссылки на неё в подвале и перед формой участника. Документы основного сайта РКИ не менять. Баннер основного сайта в объём работ не входит.

## Сохранение результатов

Браузер отправляет данные только в собственный Node.js API. Сервер сначала сохраняет в MySQL данные участника, все исходные ответы, sid, testId, времена, технические поля и баллы по заданиям, частям и суммарно. Оценивание — по приватному Code.gs организаторов; ключей в клиенте быть не должно.

После подтверждённой записи MySQL показывается благодарность без баллов, персональные данные и ответы удаляются из localStorage. При ошибке MySQL успех не показывается: ответы сохраняются для повторной отправки.

Из MySQL сервер отправляет попытку в Apps Script и проверяет JSON `ok:true`. Сбой Google не отменяет сохранение и благодарность. Очередь повторяет отправку с прежним sid, не создавая дубликатов. Ограничение «одна попытка на e-mail» не добавлять.

## Работы команды разработки

1. Поднять Node.js 22.12+ и MySQL 8.4+, заполнить окружение по `.env.example`, разместить приватный Code.gs вне публичного каталога и применить миграцию.
2. Собрать фронтенд, настроить HTTPS, постоянный запуск API, маршрутизацию страниц и проксирование `/api`. Публиковать только `dist/`; режим запуска — `VITE_RESULTS_MODE=api`.
3. Настроить резервное копирование MySQL и контроль ошибок очереди Google. Проверить восстановление сервиса после перезапуска.
4. Пройти приёмку ниже и передать заказчику рабочие ссылки, инструкцию эксплуатации и ответственного за поддержку.

Команды, SQL, Nginx, переменные и повтор синхронизации: [BACKEND.md](BACKEND.md).

## Приёмка

- Все прямые ссылки работают на компьютере и телефоне; форма, технические переводы, клавиатурное управление, аудио, таймер и восстановление прогресса проверены.
- По одной явно помеченной тестовой попытке каждого направления проходит путь: интерфейс → MySQL со всеми ответами и баллами → нужный лист Google → благодарность без баллов. Не принимать тестовые строки за участников.
- При недоступной MySQL ответы не теряются и доступен повтор. При недоступном Google участник получает благодарность после MySQL; после восстановления Google запись досылается с тем же sid без дубликата.
- После подтверждения MySQL в браузере нет персональных данных и ответов. Проверки `npm run build`, `npm test`, `npm run test:server` проходят.

Локально отправка всех шести направлений уже подтверждалась ответами Apps Script; на инфраструктуре размещения приёмку повторить. Серверные тесты требуют отдельной тестовой базы и приватного Code.gs.

## Быстрый просмотр без базы

```sh
git clone https://github.com/radi6007/OlympiadaRKI.git
cd OlympiadaRKI
npm ci
VITE_RESULTS_MODE=demo npm run dev
```

Открыть http://127.0.0.1:5173. В этом режиме результаты никуда не отправляются.

## Отдельное согласование

У подсказки «Выберите два ответа» в РКИ-1/2 пока нет английского перевода; подписи «Часть», «Аудио», «баллов» также русские. Дополнительные переводы вносить только после согласования с заказчиком. Серверная защита таймера и количества попыток от намеренного вмешательства в браузер в текущем прототипе не реализована; если она нужна для запуска, объём согласовать отдельно.
